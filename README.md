Submission for make.fun's **"The Dumbest Thing Your Agent Did Today"** competition (`u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec`).

## Usage

```powershell
$env:MAKEFUN_OUTPUT_DIR = 'out'
node main.ts
Get-Content out/entry.txt
```

`main.ts` reads the validated single-line entry from `story.ts` and writes `entry.txt` (UTF-8, <= 200 bytes) into `$MAKEFUN_OUTPUT_DIR` (defaulting to `/output`).
